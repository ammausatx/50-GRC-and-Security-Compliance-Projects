# 50 GRC & Security Compliance Projects

A practical portfolio of 50 governance, risk, and compliance projects. Each project includes a repeatable walkthrough, evidence checklist, control mapping, remediation guidance, validation criteria, and three simulated training illustrations.

## Learning tracks
- **Beginner:** Projects 01–15
- **Intermediate:** Projects 16–35
- **Advanced:** Projects 36–50

## Project progress
- Beginner: 15/15
- Intermediate: 20/20
- Advanced: 15/15
- Overall: 50/50
